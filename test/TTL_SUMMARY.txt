⏱️  DEFAULT BEHAVIOR:

  Deploy → 1 Hour Passes → Auto-Terminate (unless you extend/disable)

═══════════════════════════════════════════════════════════════════════

🔧 TERRAFORM VARIABLES ADDED:

  1. resource_ttl_minutes (default: 60)
     - Controls how long resources live
     - Range: 1-1440 minutes (1 minute to 1 day)
     - Change to extend: 120, 180, 240, etc.

  2. enable_auto_termination (default: true)
     - Enable/disable auto-cleanup
     - Set to 'false' to keep resources running forever

═══════════════════════════════════════════════════════════════════════

📝 FILE LOCATIONS:

  terraform/terraform.tfvars
  └─ Contains: resource_ttl_minutes = 60
              enable_auto_termination = true

  terraform/main.tf
  └─ Contains: Instance tags with TTL metadata

  TTL_AND_AUTO_TERMINATION.md
  └─ Complete documentation for TTL management

═══════════════════════════════════════════════════════════════════════

🚀 EXTENDING TTL (IF YOU NEED MORE TIME):

  Step 1: Edit terraform/terraform.tfvars
  
    Change:  resource_ttl_minutes = 60
    To:      resource_ttl_minutes = 120  (for 2 hours)
             resource_ttl_minutes = 180  (for 3 hours)
             etc.

  Step 2: Apply changes
  
    cd terraform
    terraform apply

  Step 3: Resources continue for the new duration

═══════════════════════════════════════════════════════════════════════

❌ DISABLING AUTO-TERMINATION (IF YOU WANT RESOURCES TO STAY):

  Step 1: Edit terraform/terraform.tfvars

    Change:  enable_auto_termination = true
    To:      enable_auto_termination = false

  Step 2: Apply changes

    cd terraform
    terraform apply

  Step 3: Resources won't auto-terminate (manual destroy required)

═══════════════════════════════════════════════════════════════════════

💥 MANUAL CLEANUP (IF YOU'RE DONE EARLY):

  cd terraform
  terraform destroy
